A production-style Azure enterprise infrastructure environment built to demonstrate practical cloud infrastructure engineering, security, observability, recovery, and Infrastructure as Code.

### Architecture Highlights

- Segmented Azure Virtual Network architecture
- Web, application, and management subnets
- Network Security Groups and traffic controls
- Private Linux application virtual machine
- SSH public-key authentication
- Azure Bastion for secure administration
- NAT Gateway for controlled outbound connectivity
- Secure Azure Storage architecture
- Azure Monitor and Log Analytics
- Azure Monitor Linux Agent and Data Collection Rules
- VM availability monitoring
- Metric and log-based alerting
- Azure Monitor Action Groups
- Backup and recovery architecture
- Automatic VM shutdown for cost optimization

The project demonstrates:

- Terraform resource imports
- Terraform state management
- Infrastructure dependency management
- Configuration drift detection and reconciliation
- Infrastructure validation
- Git-based version control
- Secure handling of Terraform state and sensitive artifacts
